Sky

A typeface designed to disappear.

An open-source sans-serif built for reading comfort first — quiet, calm, and legible at every size from a 12px UI label to a 72pt headline.

Metrics

A deliberately quiet x-height

Where Sky actually comes from

Honest status

Every release states plainly what's Roboto-derived versus modified. That's built into the version numbers.

v0.3 is a verified, proportionally refined foundation, not yet an original typeface. It's built on Roboto's real, professionally drawn outlines (Copyright Google Inc., Apache License 2.0), renamed and checked glyph-by-glyph against Sky's own design specification. That verification found Roboto's construction already meets or exceeds most of Sky's targets — a real, useful starting point, not a shortcut we're hiding.

v0.1 to v0.3 were metric and proportion engineering: the 68% x-height, spacing and side-bearing repairs, and the −12% horizontal condensing. The roadmap counts all three as 0% hand-drawn.

v0.5 is where letters start to change. "Original" there means verified, deliberate geometric modification of the foundation, each change with a documented typographic reason, never modified just to show progress.

Recent work, from the changelog
  • −12% horizontal condensing — all 9 fonts narrowed uniformly. H advance moves from ~97% of cap height to ~85%, between Helvetica (~73%) and Roboto (~97%). Y-coordinates untouched — x-height, caps, ascenders all preserved exactly. v0.3
  • Type specimen published — 8-page PDF (sky-specimen-v03.pdf): weight progression, size ramp, full alphabet, kerning pairs, paragraph tests and design notes. All fonts embedded. v0.3
  • x-height reduced to 68% of cap height — Sky's locked defining proportion. Verified in outlines and OS/2 metadata across all 9 fonts. v0.2
  • 5,901 negative side-bearing fixes — full extended glyph set audited; italic variants had ~1,100–1,200 broken glyphs from spacing scripts intersecting italic geometry. Zero known bearing problems remain. v0.2
  • Individual spacing repairs — r, f, k rsb fixed (near-zero/negative → 80–110u); K BoldItalic fixed from −159u to 90u; j lsb fixed from −66u to 60u. v0.2
  • t crossbar repositioned to correct height after x-height scaling. v0.2
  • Default line-height 1.45× — baked into ascent/descent (not lineGap). OS/2 typo ↔ hhea synced, USE_TYPO_METRICS bit set across all weights. v0.1
  • ~3.2% narrower spacing — a deliberate choice toward a quieter reading rhythm, via proportional side-bearing reduction. No letterforms compressed. v0.1

Use on the web

Self-host the WOFF2 files and declare each style you use:

@font-face {
  font-family: 'Sky';
  src: url('Sky-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
body { font-family: 'Sky', system-ui, sans-serif; }
